# Base Brand Usage Notes

This document provides practical guidance on using the Base brand assets consistently and correctly.

1) Logo usage

- Use the official Base logo files provided in this repository.
- Do not stretch, skew, or rotate the logo.
- Maintain sufficient padding around the logo to preserve visual clarity.
- Do not place the logo on backgrounds that reduce contrast or readability.

2) Color usage

- Always use the approved color palette.
- Do not introduce new brand colors without design approval.
- When using gradients, ensure they align with the Base visual identity.
- Verify color contrast meets accessibility guidelines.

3) Typography

- Use approved fonts only.
- Avoid mixing multiple font families in the same layout.
- Maintain consistent font sizes for headings, body text, and captions.
- Do not outline or distort text.

4) Backgrounds and imagery

- Prefer clean, minimal backgrounds.
- Avoid busy textures behind logos or key brand elements.
- Imagery should feel modern, technical, and neutral.
- Do not combine Base branding with conflicting third-party visuals.

5) Incorrect usage examples

Avoid the following:
- Recoloring the logo
- Applying shadows, glows, or effects
- Placing the logo inside shapes or containers
- Cropping any part of the logo

6) File export and distribution

- Export assets at appropriate resolutions for their target medium.
- Use SVG or PNG for digital products.
- Use vector formats for print whenever possible.
- Do not re-export assets with compression artifacts.

If you are unsure whether a usage is acceptable, default to simplicity or consult the Base design team before publishing.
